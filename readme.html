pastebotting Twitch Bot – Reminders

A private Twitch chat bot with a lightweight reminder module: schedule, list, and manage reminders with natural time formats. Runs in GMT+8 aka local Singapore Time.

Overview

Prefix -

Reminders are delivered in the same channel where they are created and will mention the requester in the following format: @username // HH:MM:SS <message>

tl;dr -r 30m mvp reminds you in 30 minutes to go for MVP

Commands

-remind <duration> <message> (alias: -r)

Create a new reminder. Bot will confirm when successful with reply: reminder set for <time> // <message>

  • All times displayed will be shown in HH:MM:SS format if they will fire within 24h
  • If they fire beyond 24h, they will be shown as DD/MM, HH:MM:SS

-remindlist (alias: -rlist)

List your active reminders numbered for deletion. If you have too many reminders or if reminder message is too long, the output will be clipped for Twitch Chat length limits.

@user has 2 reminders: [1] 23:13:33 rebuff 2x | [2] 09:24:00 threads

-rdelete <index> (alias: -rdel)

Delete your reminders by its index from -remindlist.

-rfresh (only for administrative purposes)

Process expired reminders immediately and reschedule future ones for the current channel. Usually done after a restart

Accepted Timecode Formats

Relative Duration (no spaces)

Supported units: h (hours), m (minutes), s (seconds). Combine freely.

15s
45m
2h
1h30m

UTC+8 Absolute Time (24 hour)

Accepts HHMM, HMM, or HH:MM. If the time has already passed today, will be scheduled on the next occurrence of that clock time.

1930   # 19:30 (7:30 PM)
07:05  # 07:05
7      # 07:00
730    # 07:30

12-hour with am/pm

Will be scheduled on the next occurrence of that clock time.

7pm
730pm
7:30pm
12:05am

Usage Examples

-r 15s hydrate
-r 2h30m start cooking
-r 1930 dinner
-r 7:30pm stream
-rlist
-rdelete 1

Notes

  • Reminders are saved internally as YYYY-MM-DD HH:MM:SS; displayed compactly for the purposes of Twitch Chat.
  • Deleting a reminder before it fires prevents delivery.
  • After restart, reminders are auto-scheduled; but it may sometimes not bind to the chat channel. Recommended to always run -rfresh first to bind bot to the channel.
